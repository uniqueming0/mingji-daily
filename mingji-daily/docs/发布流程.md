# 铭记日常 · 发布流程（M6）

## 每次发布步骤

1. **改版本号**（三处必须一致）：
   - `src-tauri/tauri.conf.json` → `version`
   - `src-tauri/Cargo.toml` → `version`
   - `package.json` → `version`
2. **更新日志**：`docs/更新日志.txt` 顶部添加新版本条目（打包时自动塞进便携 zip）
3. **前端类型检查**（必须清零 vue-tsc 报错）：
   ```powershell
   npm run build
   ```
4. **打包**：
   ```powershell
   npm run package
   ```
   - 首次会联网下载 NSIS 构建工具（几分钟，失败请重试）
   - release 编译带 LTO/strip，耗时较长（约 5~15 分钟）
5. **产物检查**（`release/` 目录）：
   - `铭记日常-便携版-vX.Y.Z-win-x64.zip`
   - `铭记日常-Setup-X.Y.Z.exe`
   - `sha256sums.txt`
6. **自测（干净环境）**：
   - 解压 zip → 双击 exe 运行 → 记一笔 → 重启数据仍在
   - 安装 exe → 桌面快捷方式 → 卸载（选保留数据）→ 重装数据仍在
   - 路径含中文/空格、非管理员账户
7. **发给朋友内测**：附 `docs/使用说明.txt`；提前告知 SmartScreen「更多信息 → 仍要运行」

## 已知事项

- **未签名**：Windows SmartScreen 与部分杀软会拦截。正式推广前建议购买代码签名证书（OV/EV）
- **WebView2**：安装版已嵌入引导器；便携版依赖系统 WebView2（Win10 21H2+/Win11 已内置）
- **体积**：当前 exe ≈ 10MB 级（Tauri）；便携 zip 不含数据目录，接收者首次运行自动建 `data/`

## 图标

- 占位图标（账本+M）：`powershell -File scripts/make-icons.ps1`
- 正式图标：准备 1024×1024 PNG → `npm run tauri icon 图标.png`（自动生成全套多尺寸）
