## 1. 软件定位

**铭记日常**是一款以"自定义记账周期"为核心的个人记账软件：

- 记录每笔收支（手动快记或批量导入）
- 按**你自己的节奏**汇总统计（发薪日、每周、项目周期……）
- 账单可附带**照片/视频**，还原消费场景
- 数据只存在本机，无需注册、无网络依赖

## 2. 快速上手（3 分钟）

### 第 1 步：记一笔

1. 左侧点「**记一笔**」
2. 选择「支出」或「收入」
3. 输入金额（如 `25.5`）
4. 点分类：先选大类（如 餐饮），再点子类（如 午餐）
5. 选择账户（现金/微信/支付宝/银行卡），日期默认今天，备注选填
6. 点「**保存**」

> 提示：软件会记住你上次用的分类和账户；保存后金额自动清空、焦点回到金额框，连续记账很快。

### 第 2 步：看明细

左侧点「**明细**」：默认显示本月账单，按天分组、每天有小计。点任意一条可编辑/删除；顶部筛选栏支持：收支类型、分类、账户、月份/日期范围、备注搜索。

### 第 3 步：看统计

左侧点「**统计**」：自动按自然月汇总，包括：

- 总收入 / 总支出 / 结余 / 日均支出 / 记账天数
- 支出分类占比（环形图，可切换一级/二级分类）
- 周期内每日支出趋势（红色虚线 = 日均线；长周期自动按月显示）
- 与上一周期对比（环比涨跌）
- **点击任意分类 → 直接跳转到该分类的账单明细**

## 4. 核心玩法：自定义记账周期

**场景：小王的工资每月 25 号到账**，他想按"25 号 → 次月 24 号"看月度总结。

1. 「设置 → 周期管理 → 新建规则」
2. 名称填"发薪月"，类型选**按月**，月起始日选 **25**
3. 保存后到「统计」页，顶部规则下拉选"发薪月"
4. 区间即显示 `07-25 ~ 08-24`，可用 ◀ ▶ 翻看历史周期，"回到本期"一键归位

**支持三种规则**（可并存多条，最多同时启用 5 条）：

| 类型 | 参数 | 示例 |
| --- | --- | --- |
| 按周 | 周起始日（周一~周日） | 每周一起始 |
| 按月 | 月起始日（1~28 日，短月自动顺延） | 每月 25 日（发薪日） |
| 自定义 | 长度 + 单位（天/周/月） | 每 14 天（双周）、每 3 周、每 2 个月 |

规则只影响统计口径，不改变账单数据；删除规则不影响任何账单。

## 5. 批量导入历史账单

### 支持的内容

- **粘贴文本**（推荐）：每行一条，如
  ```
  2025-01-15 午餐 25元
  1月16日 地铁 4元 交通
  2025-01-17 收入 工资 12000元
  昨天和朋友聚餐 128
  ```
- **文件**：.txt / .md（≤1MB）、.docx（≤5MB）；旧版 .doc 请用 Word 另存为 .docx
- 自动识别：日期（含"昨天/前天"）、金额、收支方向、分类；标题含日期范围时自动推断年份（如 `# 账本2025.09.01-09.15`）
- 支持"日期:项目金额，项目金额…"一行多笔格式（如 `9月1日:早饭5，午饭10，晚饭16，总计`）

### 操作流程

1. 「导入」→ 粘贴文本（或选文件）→ 解析
2. 预览表格中逐条核对：可改日期/金额/类型/分类/备注；识别失败的行标红、默认不勾选，补全后勾选即可
3. 勾选要导入的行 → 「确认导入」
4. 误操作？页面底部「最近导入」→ 24 小时内可撤销

### 解析失败怎么办

预览区下方「自定义解析规则」（小白模式，无需懂技术）：

- 选择每行的**分隔符**（逗号/空格/Tab/竖线）
- 按顺序选择每列的**含义**（日期/项目名/金额/分类/备注/忽略）
- 点「应用规则」→ 失败行自动补全

## 6. 照片与视频附件

- 记一笔时或编辑账单时点「📎 添加照片 / 视频」
- 限制：单笔**最多 9 张照片 + 1 个视频**（超限会整批拦截并提示，需先删除多余的）
- 照片自动生成缩略图，点开可全屏查看；视频可直接播放
- 文件会被复制进数据目录（删除原文件不影响查看）；删除账单会一并删除附件
- 占用情况见「设置 → 通用 → 媒体附件」

## 7. 数据安全与搬家

### 自动保护

- 每次**退出软件自动备份**数据库（保留最近 7 份）
- 「数据管理 → 检查完整性」可随时体检数据库

### 手动备份 / 恢复

- 「立即备份（仅数据）」或「立即备份（含照片/视频）」
- 恢复：在备份列表点「恢复」（**会替换当前数据**，恢复后重启应用生效）

### 导出

- **CSV**：账单明细，Excel 直接打开
- **JSON**：全部数据（账单/分类/账户/周期规则/媒体清单），用于迁移或归档

### 数据位置与搬家

| 版本 | 数据目录 |
| --- | --- |
| 便携版 | 程序同目录 `data\`（整个文件夹拷走 = 搬家完成） |
| 安装版 | `C:\Users\你的用户名\AppData\Roaming\铭记日常\` |

搬家工具：「数据管理 → 数据目录迁移」选择新文件夹，重启后生效。

## 8. 常见问题 FAQ

| 问题 | 解答 |
| --- | --- |
| 双击提示"Windows 已保护你的电脑" | 软件暂未商业签名。点「更多信息 → 仍要运行」即可 |
| 双击后没反应 | 需 Win10 21H2+ / Win11（自带 WebView2）；老系统请安装微软 WebView2 运行时 |
| 如何彻底卸载 | 便携版删除整个文件夹；安装版在「设置 → 应用」卸载（数据默认保留） |
| 数据会上传吗 | 不会。默认完全离线；未来 AI 功能需主动开启并自备 Key |
| 分类删不掉 | 已被账单使用/含子分类的分类只能「停用」，这是防误删保护 |
| 账单能改吗 | 明细页点任意账单即可编辑（金额/分类/账户/日期/备注/附件） |
| 记错了怎么办 | 明细里删除；批量导入的可整批撤销（24 小时内） |
