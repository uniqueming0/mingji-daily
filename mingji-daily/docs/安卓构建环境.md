# 安卓端构建环境说明（Windows）

> 本文档记录「铭记日常」安卓版在 Windows 上的完整构建环境与踩坑解决方案。
> 环境搭好后，日常构建只需最后两条命令。

---

## 一、一次性环境准备

| 组件 | 安装方式 | 建议路径（**必须全英文**） |
| --- | --- | --- |
| JDK 17 | `winget install --id EclipseAdoptium.Temurin.17.JDK --source winget` | 默认即可 |
| Android 命令行工具 | 下载 `commandlinetools-win-*.zip` 解压 | `D:\Android\Sdk\cmdline-tools\latest\`（含 `bin` 与 `lib`） |
| Android SDK 组件 | `sdkmanager`（见下） | `D:\Android\Sdk\` |
| Rust Android 目标 | `rustup target add ...` | — |

```powershell
# SDK 组件（NDK 约 700MB，断了重跑同一条即可续传）
$env:ANDROID_HOME = "D:\Android\Sdk"
& "$env:ANDROID_HOME\cmdline-tools\latest\bin\sdkmanager.bat" --sdk_root=$env:ANDROID_HOME `
  "platform-tools" "platforms;android-34" "platforms;android-36" "build-tools;34.0.0" "build-tools;35.0.0" `
  "ndk;27.0.12077973"

# Rust 目标
rustup target add aarch64-linux-android armv7-linux-androideabi i686-linux-android x86_64-linux-android
```

## 二、环境变量（**最关键的部分**）

```powershell
[Environment]::SetEnvironmentVariable("ANDROID_HOME", "D:\Android\Sdk", "User")
[Environment]::SetEnvironmentVariable("NDK_HOME", "D:\Android\Sdk\ndk\27.0.12077973", "User")
[Environment]::SetEnvironmentVariable("JAVA_HOME", "C:\Program Files\Eclipse Adoptium\jdk-17.0.20.101-hotspot", "User")

# ★ 中文用户名必看：下面三个缓存必须重定向到英文路径
[Environment]::SetEnvironmentVariable("RUSTUP_HOME", "D:\Rust\rustup", "User")
[Environment]::SetEnvironmentVariable("CARGO_HOME", "D:\Rust\cargo", "User")
[Environment]::SetEnvironmentVariable("GRADLE_USER_HOME", "D:\Rust\gradle", "User")
[Environment]::SetEnvironmentVariable("ANDROID_USER_HOME", "D:\Android\user", "User")
```

迁移已有缓存（复制一次即可，原目录可保留作备份）：

```powershell
robocopy "$env:USERPROFILE\.rustup" "D:\Rust\rustup" /E /NFL /NDL /NJH /NJS /R:1 /W:1
robocopy "$env:USERPROFILE\.cargo"  "D:\Rust\cargo"  /E /NFL /NDL /NJH /NJS /R:1 /W:1
robocopy "$env:USERPROFILE\.gradle" "D:\Rust\gradle" /E /NFL /NDL /NJH /NJS /R:1 /W:1
```

> 复制 `.gradle` 前先 `cd src-tauri\gen\android; .\gradlew.bat --stop`，否则 `.lock` 文件被占用会报"另一个程序已锁定文件"（少量 lock 失败无妨，Gradle 会重建）。

## 三、Windows 系统设置

1. **开发人员模式**（必须）：`设置 → 系统 → 开发者选项 → 开发人员模式` 打开
   - 原因：Tauri 构建时会把 `.so` **符号链接**进安卓工程，普通权限不允许创建符号链接
2. **硬件加速**（跑模拟器才需要）：`设置 → 系统 → 可选功能` 或管理员执行
   ```powershell
   Enable-WindowsOptionalFeature -Online -FeatureName HypervisorPlatform -All
   ```
   重启后 `emulator -accel-check` 应显示 `WHPX ... is usable`

## 四、国内镜像加速

**1. Gradle 发行包**（`src-tauri/gen/android/gradle/wrapper/gradle-wrapper.properties`）：

```
distributionUrl=https\://mirrors.cloud.tencent.com/gradle/gradle-8.14.3-bin.zip
```

**2. 依赖仓库**（`src-tauri/gen/android/build.gradle.kts` 与 `buildSrc/build.gradle.kts`）：

```kotlin
maven("https://maven.aliyun.com/repository/google")
maven("https://maven.aliyun.com/repository/public")
```

**3. 全局兜底**（`D:\Rust\gradle\init.gradle`，见下）——**必须用无 BOM 的 UTF-8 写入**，否则 Gradle 报 `Unexpected character: '锘'`：

```powershell
$content = @'
allprojects {
    repositories {
        maven { url 'https://maven.aliyun.com/repository/google' }
        maven { url 'https://maven.aliyun.com/repository/public' }
        google()
        mavenCentral()
    }
}
'@
[System.IO.File]::WriteAllText("D:\Rust\gradle\init.gradle", $content, (New-Object System.Text.UTF8Encoding($false)))
```

## 六、踩坑记录（中文用户名 / Windows）

| 现象 | 根因 | 解决 |
| --- | --- | --- |
| `ld.lld: cannot open ...\.rustup\...\libstd-*.rlib` | NDK 链接器不支持非 ASCII 路径 | `RUSTUP_HOME` 指向英文路径 |
| Kotlin：`this and base files have different roots` / `source file not found: ...u5F90...` | Kotlin 编译器无法处理含中文的路径（tauri 源码在 cargo 注册表里、依赖 jar 在 gradle 缓存里） | `CARGO_HOME`、`GRADLE_USER_HOME` 指向英文路径 |
| APK 构建报 `Creation symbolic link is not allowed` | Windows 默认禁止创建符号链接 | 开启开发人员模式 |
| Gradle：`Could not compile initialization script ... Unexpected character: '锘'` | PowerShell 5.1 的 `Set-Content -Encoding UTF8` 写入 BOM | 用 `[System.IO.File]::WriteAllText(..., UTF8Encoding($false))` |
| `tauri.settings.gradle` 里仍是旧路径 | 该文件自动生成，且生成时 `CARGO_HOME` 未生效 | 设好变量后删除该文件重建 |
| `avdInfo_setLastRunQemuVersion: Could not write file: ...\.android\...` | 同上，`.android` 目录含中文路径 | 设置 `ANDROID_USER_HOME` 到英文路径 |
| 模拟器：`x86_64 emulation currently requires hardware acceleration` | 未安装 WHPX/AEHD | 开启 HypervisorPlatform 并重启 |
| npm/cargo 换缓存路径后首次构建很慢 | 指纹变化触发全量重编译 | 正常，一次性的 |

## 七、给朋友（非开发者）的安装说明

把 `app-universal-debug.apk` 发过去 → 手机点击安装 → 若提示"未知来源应用"，在弹窗里选"允许"即可。

> 正式对外分发（上架/长期）建议做 **release 签名 APK**：需要生成 keystore 并在
> `src-tauri/gen/android/keystore.properties` 配置签名信息，再用
> `npm run tauri -- android build --apk --target aarch64`（release）构建。
