============================================
  铭记日常 · 使用说明（新手 3 分钟上手版）
  版本 v1.0.0
============================================

一、这是什么？
------------------------------------------------------------
一个帮你记账的本地软件：记下每一笔花销和收入，
按你自己的节奏（每月 25 号发薪日 / 每周 / 任意周期）做总结，
还能给账单配上照片，以后回想"这钱花哪了"一目了然。
所有数据只保存在你自己的电脑里，完全离线。

二、三步开始用
------------------------------------------------------------
第 1 步：记一笔
  左侧点「记一笔」→ 选 支出/收入 → 输入金额
  → 点分类（如 餐饮 > 午餐）→ 选账户 → 点「保存」。
  平时记账 5 秒搞定；「保存」后会记住你上次的分类和账户。

第 2 步：看明细
  左侧点「明细」→ 默认显示本月账单，按天分组。
  点任意一条可修改或删除；顶部可按 分类/账户/收支 筛选，
  也能搜索备注关键词。

第 3 步：看统计
  左侧点「统计」→ 自动按"自然月"汇总：
  收入 / 支出 / 结余 / 分类占比图 / 每日趋势 / 与上月对比。
  点某个分类可以直接跳到对应的账单明细。

三、好用的功能
------------------------------------------------------------
1. 按自己的周期统计（发薪日神器）
   设置 → 周期管理 → 新建规则：
   · 按月：选每月几号开始（比如 25 号发工资 → 统计 25 号到次月 24 号）
   · 按周：选周几开始
   · 自定义：每 N 天 / N 周 / N 个月
   建好后到「统计」页顶部切换即可。

2. 给账单配照片/视频
   记一笔时点「📎 添加照片 / 视频」选文件，保存后
   在「明细」里点开该账单即可查看（单笔最多 9 张照片 + 1 个视频）。

3. 批量导入以前的账单
   「导入」页 → 粘贴文本（每行"日期 项目 金额"，如：2025-01-15 午餐 25元）
   或选择 txt / md / docx 文件 → 自动识别后逐条检查 → 确认导入。
   导入后 24 小时内可在「导入」页底部撤销。

4. 数据安全
   「数据管理」→ 立即备份 / 恢复、导出 CSV（Excel 可直接打开）。
   每次退出软件时自动备份（保留最近 7 份），不怕误删。

四、数据存在哪里？怎么搬家？
------------------------------------------------------------
· 便携版：程序同目录的 data\ 文件夹（整个文件夹拷走 = 全部带走）
· 安装版：C:\Users\你的用户名\AppData\Roaming\铭记日常\
· 换电脑：把 data 文件夹拷到新电脑对应位置，或
  「数据管理 → 导出全部数据 JSON」保存留档。

五、常见问题
------------------------------------------------------------
Q：双击后提示"Windows 已保护你的电脑"？
A：本软件暂未购买商业签名。点「更多信息」→「仍要运行」即可。

Q：双击后没反应？
A：需要 Windows 10 21H2 或更新版本（Win11 均可）。
   老系统请先安装微软 WebView2 运行时。

Q：如何彻底卸载？
A：便携版直接删除整个文件夹；安装版在「设置 → 应用」中卸载。
   ※ 安装版请用正规方式卸载；若手动删除了程序文件夹，
   再次安装可能提示"无法卸载旧版本"，请联系开发者获取清理工具。

Q：我的数据会上传吗？
A：不会。软件默认完全离线，账单只存在你的电脑上。
   （未来的 AI 功能也需要你主动开启并自己填 Key 才会联网）
